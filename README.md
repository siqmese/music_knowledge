# Music Lyricist Knowledge Graph

歌手（作詞家）ごとに「本人が作詞した楽曲」を収集・構造化し、ナレッジグラフとして可視化・分析するためのデータプロジェクトです。

## フォルダ構成

```text
music_knowledge_graph/
├── README.md
├── schema/
│   └── knowledge_graph.schema.json   # 歌手横断の共通ナレッジグラフJSONスキーマ
├── scripts/
│   ├── build_graph.py                # artist.json + songs.json -> knowledge_graph.json & webバンドル生成
│   └── extract_lyrics_tokens.py      # 手元の歌詞テキスト(.txt)から実出現回数ベースでトークン抽出
├── artists/
│   └── shiina_ringo/                 # 歌手ごとのフォルダ
│       ├── artist.json               # 歌手・作詞家プロフィール、活動期、収録方針
│       ├── songs.json                # 楽曲単位の構造化マスターデータ（lyric_tokens含む）
│       ├── knowledge_graph.json      # 統合ナレッジグラフ JSON（楽曲・語彙・テーマ・人脈すべて）
│       └── lyrics_knowledge_graph.json # 歌詞ワード＆共起関係に特化したナレッジグラフ JSON
└── web/                              # インタラクティブ・ナレッジグラフ可視化ビューア
    ├── index.html                    # ブラウザで直接開けるビューア本体（サーバー不要）
    ├── style.css
    ├── app.js
    └── data/
        ├── artists_index.json        # 全アーティスト一覧マニフェスト（自動生成）
        └── bundle.js                 # ローカル直開き用データバンドル（自動生成）
```

## 可視化ビューアの使い方

[web/index.html](web/index.html) をそのままブラウザで開くだけで動作します（外部CDN・ローカルサーバー不要）。

- **8つの表示プリセット**:
  1. **歌詞ワード（共起）**: 歌詞に頻出する単語・トークンの共起ナレッジグラフ（よく出る単語ほど大きなノード、一緒に出やすい単語ほど太い線で接続）
  2. **楽曲×歌詞ワード**: 楽曲ノードと頻出単語ノードを直接結んだ二部グラフ
  3. **世界観（テーマ×モチーフ）**: 楽曲と歌詞テーマ・モチーフのクラスターを探索
  4. **曲間リンク・対称構造**: アルバム内のシンメトリー対称ペアや「いろは歌」「花札」「新宿」などの曲間リンクのみを表示
  5. **地名・都市マップ**: 新宿・東京・銀座・福岡・パリなどの登場地名ネットワーク
  6. **人脈・コラボ・提供**: 作曲者・バンド・デュエット相手・楽曲提供先との関係図
  7. **作詞技法・文体**: 旧仮名遣い・対称構造・多言語詞・掛詞と感情トーンの分布
  8. **フルグラフ**: 全ノード種別を自由にON/OFF
- **操作**: ドラッグで移動・ノード配置、ホイールでズーム、クリックで右パネルに詳細表示、ダブルクリック（または「近傍のみ抽出」）で1ホップ周辺ネットワークを抽出、上部「統計」ボタンでランキング表示、PNG画像保存にも対応。

## データ設計

著作権保護の観点から歌詞全文は保存せず、楽曲メタデータと歌詞から抽出した以下の知識要素をノード・エッジとして構造化しています。

- **ノード種別 (`nodes[].type`)**:
  - `Artist`（作詞家・作曲家・バンド・コラボ相手・提供先アーティスト）
  - `Song`（楽曲）
  - `Album`（収録アルバム）
  - `Era`（活動期）
  - `Theme`（歌詞の主題・テーマ）
  - `Motif`（具体的モチーフ・象徴）
  - `Place`（歌詞・タイトルに登場する地名・場所）
  - `Style`（旧仮名遣い、対称構造、掛詞、多言語詞などの作詞技法）
  - `Mood`（感情・雰囲気トーン）
  - `Language`（使用言語：ja / en / fr / es 等）

- **エッジ種別 (`edges[].type`)**:
  - `LYRICIST_OF`, `COMPOSER_OF`, `PERFORMED_BY`, `WRITTEN_FOR`, `COLLABORATED_WITH`
  - `INCLUDED_IN`, `BELONGS_TO_ERA`, `WRITTEN_IN_LANGUAGE`
  - `HAS_THEME`, `HAS_MOTIF`, `MENTIONS_PLACE`, `USES_STYLE`, `HAS_MOOD`
  - `RELATED_SONG`（アルバム内の対称ペア、テーマ対、続編、セルフカバー関係など）

- **グラフ規模**: 365ノード / 3,758エッジ

## 新しい歌手を追加・グラフを再生成する方法

1. `artists/<artist_slug>/` フォルダを作成し、`artist.json` と `songs.json` を配置します。
2. 以下のコマンドで整合性チェックと `knowledge_graph.json` の生成を実行します。

```bash
# 特定の歌手のみ生成
python scripts/build_graph.py --artist shiina_ringo

# 全アーティストを一括生成
python scripts/build_graph.py --all
```
